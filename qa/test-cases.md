Чек-лист тест-кейсов MVP (Postman / API)



&#x20;1. Регистрация пользователя (POST /api/auth/register)

\- TC-01 (Позитивный): Регистрация с валидными данными (email, логин, пароль).  Ожидаемый результат: статус 201 Created, возвращаются данные пользователя (без пароля в открытом виде).

\- TC-02 (Негативный): Повторная регистрация с уже существующим email.  Ожидаемый результат: статус 400 Bad Request или 409 Conflict, ошибка о занятом email.

\- TC-03 (Негативный): Регистрация с пустым полем пароля или некорректным форматом email.  Ожидаемый результат: статус 400 Bad Request, ошибка валидации.



&#x20;2. Авторизация и JWT (POST /api/auth/login)

\- TC-04 (Позитивный): Вход с правильным email и паролем.  Ожидаемый результат: статус 200 OK, в ответе приходит валидный JWT-токен.

\- TC-05 (Негативный): Вход с неверным паролем.  Ожидаемый результат: статус 401 Unauthorized.

\- TC-06 (Негативный): Вход с несуществующим email.  Ожидаемый результат: статус 401 Unauthorized или 404 Not Found.



&#x20;3. Получение данных пользователя (GET /api/users/me)

\- TC-07 (Позитивный): Запрос с валидным токеном в заголовке Authorization: Bearer <token>.  Ожидаемый результат: статус 200 OK, возвращается профиль текущего пользователя.

\- TC-08 (Негативный): Запрос без токена или с поддельным/просроченным токеном.  Ожидаемый результат: статус 401 Unauthorized.



&#x20;4. Работа с досками (POST /api/boards, GET /api/boards/:id)

\- TC-09 (Позитивный): Создание новой доски авторизованным пользователем (с валидным JWT).  Ожидаемый результат: статус 201 Created, возвращается объект доски с присвоенным id.

\- TC-10 (Негативный): Попытка создать доску без токена авторизации.  Ожидаемый результат: статус 401 Unauthorized.

\- TC-11 (Позитивный): Получение существующей доски по её ID (с валидным JWT).  Ожидаемый результат: статус 200 OK, возвращаются данные доски и её элементы (стикеры, текст, фигуры).

\- TC-12 (Негативный): Запрос доски по несуществующему ID.  Ожидаемый результат: статус 404 Not Found.
